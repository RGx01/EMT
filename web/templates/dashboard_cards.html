Dashboard cards
Show EMT's Billing tab or its heatmap on a Home Assistant dashboard, as a Webpage card. Each card's address carries a card key: it lets the card read those two charts and nothing else, so a card needs no sign-in and can't change anything.
Loading…
  1. Copy a card's address.
  2. On a dashboard: ⋮ → Edit dashboard → Add card → Webpage, and paste it as the URL.
Add &theme=light or &theme=dark to a card's address to fix its colours. A card works when Home Assistant is opened over http on your network; a browser won't show it inside Home Assistant opened over https.
A new key replaces the old one: every card using the old one stops until you paste its new address. Do this if a card's address has been shared where it shouldn't have been.
