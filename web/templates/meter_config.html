Disconnect Octopus & clear credentials?
This stops API polling immediately, deletes your stored API credentials, and switches the data source to local meter sensors.

Your billing history is kept — readings and costs already settled stay exactly as they are; nothing is re-priced.

You'll then need local meter sensors to resume collecting new data — the import reading, and the import rate and standing charge (and export rate, if you export), since prices no longer come from Octopus. Or reconnect: this is reversible — re-entering your API key reconnects.
